Fast. Safe. Powerful.

Bolt is a production-ready runtime designed for teams who need high performance, predictable startup time, and secure extensibility. The distribution is docs-first — see the documentation before downloading so you know what you're installing.

Fast Low overhead runtime with C-like startup characteristics and optimized memory usage.
Easy to adopt Clear interfaces, robust CLI tooling, and concise examples in the documentation.
Secure & Extensible Sandboxed plugin model and observability built in for safe production workflows.
