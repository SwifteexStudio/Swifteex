Getting Started

The Bolt Updater (boltupd.exe) is a specialized utility designed to manage the lifecycle of your Bolt environment. Before execution, ensure the binary is located in an accessible directory.

01. Locate the boltupd.exe binary in your system downloads folder.

02. Initialize the Command Prompt (Terminal) by pressing Win + R, typing cmd, and pressing Enter.

03. Navigate to the directory containing the updater and execute the base command to verify functionality:

boltupd

The utility will initialize and display the available operations interface:

Bolt Updater Usage: boltupd -check-for-upd-latest Check if an update is available boltupd --upd --latest Download and install the latest version boltupd --bkp Create a backup of the local Bolt version folder.

Installation Procedure

To perform a clean installation of the Bolt Runtime, follow the standardized deployment workflow outlined below.

Step 1: Version Verification

Query the remote repository to identify the latest stable build and evaluate your local installation state.

boltupd -check-for-upd-latest

The system will return a status report similar to the following:

Checking for updates... [Info] No local Bolt installation found in C:\Program Files\Bolt. [Info] Latest version: 170 [Result] Update/Installation required.

Step 2: Automated Deployment

Upon verification, initiate the automated download and installation sequence.

boltupd --upd --latest

The utility will fetch the secure Bolt installer package and begin the system integration. Follow any on-screen prompts provided by the installer to finalize the setup.

Maintenance & Backups

To preserve your current configuration before applying major updates, it is recommended to utilize the native backup flag.

boltupd --bkp

This creates a timestamped archive of your local Bolt binaries within the application directory.

Critical Requirement: Path Validation The Bolt Updater is engineered to interface exclusively with installations located in the standard directory: C:\Program Files\Bolt. If the Bolt Runtime has been deployed to a non-standard path, the updater will fail to synchronize and apply patches.
